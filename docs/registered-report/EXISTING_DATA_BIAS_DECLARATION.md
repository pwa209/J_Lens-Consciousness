# Existing-data and prior-work declaration

At the 2026-08-11 prospective boundary, four machine conditions had completed
20 seeds each (80 runs total). These results are prior work and cannot constitute
prospectively registered tests. The unlimited shared-state condition was added
after the boundary. All machine outcomes will be available before confirmatory
human outcomes, so architecture hypotheses and all analysis choices must be
fixed at Stage 1 and the machine arm must be described transparently as observed.

Human Gabor sub-10 had generated all five fold outputs. The analyst inspected
preprocessing QC and fold-3 model QC, but did not inspect condition contrasts or
group results. Somato sub1 processing was attempted and failed; Kronemer pilot
participants were selected but not processed through the complete human
analysis. Gabor sub-10, Somato sub1, Kronemer 223_RP_EEG, and Kronemer 238_NRP
are excluded from all confirmatory analyses.

Bias controls are: a content-blind hash inventory; exclusion of pilot
participants; an IPA-enforced execution gate; discovery/replication separation;
training-only transforms; architecture-independent equal metric weights; fixed
equivalence bounds; separate shape and magnitude outcomes; complete reporting of
all five architectures; and robustness analyses that cannot promote a failed
primary result. This declaration does not assert eligibility. PCI RR/Cortex must
confirm whether these controls meet the required existing-data bias level.
